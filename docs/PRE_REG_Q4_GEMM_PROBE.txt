PRE_REG_Q4_GEMM_PROBE.txt -- 方向 A（C tile 口径手写汇编验证快核）立项探针
跑前冻结（探针先行）。ASCII 判据编号。禁止事后改阈值。

================================================================================
0. 要决定什么
================================================================================
是否立项「方向 A」：新写一个「C tile 口径（16 元素一次 + lo/hi 双 acc + f32
scale）的手写汇编批式 GEMM」作为投机解码的验证快核，使验证与 decode（C tile）
位级一致、且验证足够快（< 108 ms/token）从而投机赢过无 spec。

依据 §4.6.1 数学门槛：V < D×α，D=175ms（decode 单 token）。α=0.62（自由文本）
时须 V<108ms；α=0.76 时须 V<133ms。

本探针不写汇编、不推断「手写汇编能快多少」，只量 C tile intrinsic 批式 GEMM
的「纯内存读地板 M」（去掉全部点积计算、只读权重+xq+xd）。M 是任何「同口径」
优化（含手写汇编）的乐观下界：再快也不可能快过纯读地板。

================================================================================
1. 背景数字（来自本轮 L1/端到端实测，8B-q4，RK3588）
================================================================================
  C tile 批式现状   gu+down = 111 ms/token  （[PF-PROF] gu=73.2 down=38.2，tokens=8）
  decode 单 token   总 175 ms（[DEC-SINGLE]，gu 81.7 + down 41.6 = 123，lm 12.8）
  asm 快路 33-token gu+down = 41.5 ms/token （[PF-PROF] tokens=33 首轮，摊薄 ÷33）
  asm vs C tile 批式 = 2.7×；该 2.7× 未拆解「手写汇编+摊薄」vs「32元素+f16 scale」

================================================================================
2. 装置
================================================================================
板端 /mnt/emmc/specl1/（本地工作树独立构建，不动 kestrel_pull 共享树）。
模型 /mnt/emmc/Modl/8b-q4。同 boot、TH=4（VLLM_THREADS=4，OMP 未设）、
每格一个进程、两格交替 2 轮取中位。

新开关（均默认关、仅探针用）：
  VLLM_Q4_CTILE=1  q4x4_gemm_batched 强制 n_batch（含 >3）走 C tile worker，
                   （恢复「验证强制 C tile」逻辑，独立开关，与 VEXACT 解耦）
  VLLM_Q4_PROBE=1  C tile worker 内纯读：循环照旧读权重 bq + xq + xd，但跳过
                   vdot/vcvt/vfma（累加器不更新），读到的字节累加进一个 volatile
                   sink 防编译器消去 load。输出为垃圾（预期，只量时间）。
自证：L0 打 `[Q4CTILE] engaged`，L1 打 `[Q4PROBE] engaged`；未设时无此两行。

测量：`--stream-test --stream-ctx 8 --prefill-batch 8 --stream-n 1` +
VLLM_DEC_PROF=1；指标取 [PREFILL-KERNELS] 的 GATEUP+DOWN 之和（ms，除以 tokens
得 per-token）。n 取 32（--stream-ctx 8 的固定 prompt 长度）。

================================================================================
3. 臂与判据（冻结）
================================================================================
  L0   VLLM_Q4_CTILE=1                         ->  C_tile_now（C tile 批式现状）
  L1   VLLM_Q4_CTILE=1 VLLM_Q4_PROBE=1         ->  M（纯读地板）

  G0（validity，否则整轮 VOID）
    - L0 与 L1 各自打印自证行，且 n=32、GATEUP+DOWN > 0、两格 tokens 相等。
    - L1 的 TOKIDS 预期与 L0 不同（纯读产出垃圾）——这不是 VOID，是预期。
    - 无开关的对照臂（--prefill-batch 8，走 asm）TOKIDS 必须 = 100062（探针零
      副作用自证：VLLM_Q4_CTILE 默认关时行为逐位不变）。

  P-Q4-1（前提，判断 C tile 是否计算受限）
      M / C_tile_now < 0.80
        即纯读去掉计算后剩 <80% 时间 => 计算占 >20%，手写汇编有榨取空间。
        若失败（M/C_tile_now >= 0.80，即内存受限）=> 方向 A 关闭，不写汇编。

  P-Q4-2（决策，立项门槛）
      上界比 = C_tile_now / M >= 1.30（等价 M < 85ms）
        达标 => 立项方向 A（手写汇编乐观下界 < 85ms < 108ms 阈值）。
        1.30~1.50 => 弱信号，仅授权「试写汇编 + 自带 A/B 回退」。
        < 1.30   => 关闭方向 A，「唯一出路」坐实无解，投机解码在本引擎收官。

  两判据均在 2 轮中位值上评估；同 boot 复测抖动应 <=1%（历史）。

================================================================================
4. 已知局限（引用结果时必须同引）
================================================================================
(a) 纯读地板是乐观上界：它假设「同口径手写汇编」能把计算榨到 0。实际手写汇编
    仍保留 vdot/vcvt/vfma（16 元素一次），只能逼近 M、到不了 M。故 P-Q4-2 达标
    只授权「立项试写」，不是收益承诺。
(b) 本探针量的是「C tile 口径」的内存地板；它不重开 asm 快路（32元素+f16）与
    decode 的位级对齐问题（§4.5 已证伪 asm==M4f）。
(c) 纯读探针跳过 scores/imp 等注意力侧流量，仅覆盖 GEMM（qkv/o/gu/down 的
    q4x4_gemm_batched → C tile worker）。
(d) 若 P-Q4-2 达标，立项后仍需：写汇编 → L1 位级对拍（vs C tile 逐字节）→
    端到端三臂（无 spec / spec+C tile / spec+快核）→ 按 §6 go/no-go 门槛。

================================================================================
5. 实测结果与裁决（2026-09-24 追加，判据已冻结、未改动）
================================================================================
装置：板端 /mnt/emmc/specl1/（独立构建 build/，exe 953544B），模型 8b-q4，
同 boot 交替 2 轮，TH=4，--stream-ctx 8（32 token）--prefill-batch 8 --stream-n 1，
指标取 [PREFILL-KERNELS] GATEUP+DOWN（ms，/32 得 per-token）。

  L0（CTILE）:  2416.8+1223.4=3640.2 ; 2426.0+1227.0=3653.0  中位 3646.6ms -> 114.0ms/tok
  L1（PROBE）:  1581.9+778.0 =2359.9 ; 1570.9+773.1 =2344.0  中位 2352.0ms ->  73.5ms/tok

  G0  PASS：两臂自证行 engaged；n=32 相等、GATEUP+DOWN>0；无开关对照 TOKIDS=100062
      （默认关逐位不变）；L1 TOKIDS != L0（纯读产垃圾，预期）。

  P-Q4-1  PASS：M/C = 2352/3647 = 0.645 < 0.80（计算占 ~35%，有榨取空间）
  P-Q4-2  PASS：C/M = 3647/2352 = 1.55 >= 1.30（M=73.5ms < 85ms 阈值）

  裁决：方向 A 立项 —— 授权「试写 C tile 口径（16 元素一次 + lo/hi + f32 scale）
        的手写汇编批式 GEMM + 自带 A/B 回退」。

  兑现约束（同 (a)）：1.55 是乐观上界，非收益承诺。后续须：
    (1) 写汇编 → VLLM_SPECL1 位级对拍 vs C tile（逐层 KV 行 0 差异）。
    (2) 端到端三臂，确认快核 per-token < 108ms（α=0.62）才真正赢。
    (3) 若汇编落点 >= 108ms，如实关闭（纯读地板未能兑现）。
