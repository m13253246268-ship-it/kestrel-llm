长上下文淘汰 (L3)

⚠ 已开 --l3-evict 但未开 P3 门：--prefix-kv 会被静默打掉，多轮追问将全量重算 prefill。建议开启上面这项。
0 = prefill 后总是淘汰；N>0 = 上下文达到 N tokens 才启动淘汰（实测口径 128，越小越白付驱逐开销）。
路径可填 eMMC 挂载点（如 /mnt/emmc/kv_l3.bin）；最大大小 0 = 不限制。
每用户独立缓存文件，闲置超 TTL 分钟自动删除（0 = 不清理）。
开 --l3-evict 时务必同时开上面那项 P3 门，否则 KV 前缀复用会被静默打掉。

有效优化组合（实测台账）点「套用」把该组合填进表单；全部为同一二进制单开关 A/B 实测

组合适用场景 关键开关实测收益 平台
平台标签： 省 RAM 内存受限场景有效 · x86 已复现 已在本地 x86 独立复现 · x86 无效 x86 上无收益/负收益（板端 ARM 数据仍以板端为准）
三条铁律：① 开 --l3-evict 必须同时开 VLLM_L3_PREFIX_REUSE=1； ② --sparse-k 不得低于 32；③ 加密 VQF 只能全层驻留（不可用逐层 VLLM_VQF_STREAM）。
互斥：--kv-q4 × --sparse-attn；--spec × {--sparse-attn, --l3-evict, --batch-max}。
